# 风格手牌范围与诈唬

Date: 2026-11-02

内置牌手现在从 `texas_holdem/ai/preflop_ranges.json` 查询翻牌前范围。
这是一份可编辑的启发式选牌表，初始内容由原分数阈值展开，现已补齐位置并修正早位/中位倒置，不代表 GTO 或求解器策略。

## 如何读表

六种风格各有十人桌的十个范围角色：UTG、UTG+1、UTG+2、MP、LJ、HJ、CO、BTN、SB、BB。每个角色包含：

| 字段 | 用途 |
| --- | --- |
| `enter` | 面对常规盲注价格时允许入池的牌 |
| `raise` | 允许主动加注的牌 |
| `call_raise` | 面对更高跟注价格时允许跟注的牌 |
| `three_bet` | 允许再加注的牌 |

`AA` 是一对 A；`AKs` 是同花 AK；`AKo` 是不同花 AK。每种牌写高点数在前，10 写作 T。未列出的牌不属于该范围。修改后重启应用生效。

例如，BTN 的 `76s` 在 nit、tight_aggressive 的入池范围外，在 loose_aggressive、calling_station 的入池范围内，在 maniac 的加注范围内。相同的跟注价格下，风格就能产生不同选择。

入表只是行动资格，并非每次都行动。原有跟注价格、筹码、概率选择仍然生效；非常好的底池赔率以及 calling_station 的小盲补齐可例外跟注。免费行动时弱牌过牌。范围表不指定下注金额，不改变合法行动校验。

这里保留原有价格分类：需跟注金额不超过 10 走盲注价格分支，更高金额走面对加注分支。它还不是按有效筹码、实际开池者位置、加注次数拆分的完整范围系统。自定义 profile 参数继续使用原分数阈值，避免把自定义参数静默覆盖成内置风格。

## 桌上人数与位置

牌手座位从小盲开始编号，范围角色按距按钮还有几个座位决定。显示名称采用以下约定：

| 人数 | 小盲、大盲之后的位置顺序 |
| --- | --- |
| 2 | BTN 同时是 SB，另一席 BB |
| 3 | BTN |
| 4 | CO → BTN |
| 5 | HJ → CO → BTN |
| 6 | UTG → HJ → CO → BTN |
| 7 | UTG → LJ → HJ → CO → BTN |
| 8 | UTG → MP → LJ → HJ → CO → BTN |
| 9 | UTG → UTG+1 → MP → LJ → HJ → CO → BTN |
| 10 | UTG → UTG+1 → UTG+2 → MP → LJ → HJ → CO → BTN |

六人桌 UTG 使用十人桌 LJ 的范围角色，八人桌 UTG 使用十人桌 UTG+2 的角色，十人桌 UTG 使用最紧的 UTG 角色。因此同名 UTG 不会无视身后人数。位置插值参数从 UTG 的 -0.05 逐步增至 BTN 的 +0.08；它们是可调整的启发式参数，不是求解器结果。大于十人的自定义桌仍保留唯一座位名，额外早位范围收紧至 UTG。

六种风格只是参数预设，不是扑克风格的完整分类。Balanced 是本项目折中参数，不等于 GTO。自定义 profile 也会使用人数修正后的位置参数。

## 翻牌后诈唬

当胜率低于 45%、无需跟注、未走翻牌持续下注分支时，普通诈唬和半诈唬使用风格参数：

| 风格 | 单挑、有位置、安全牌面的纯诈唬概率 | 同条件半诈唬概率 |
| --- | ---: | ---: |
| nit | 4% | 8% |
| tight_aggressive | 11% | 22% |
| loose_aggressive | 18% | 36% |
| calling_station | 4% | 8% |
| maniac | 30% | 60% |
| balanced | 10% | 20% |

“有位置”现在由公开座位及仍能行动的对手计算，而不是绝对座位评分。CO 对尚未弃牌的 BTN 无位置；BTN 弃牌后，早位也可能成为最后行动者；单挑 BTN/SB 翻牌后有位置。全下玩家不参与行动顺序比较，但仍计入胜率和多人压力折扣。

没有可行动对手且胜率低于 45% 时直接过牌，包括持续下注机会。缺少公开座位上下文的旧直接调用仅把 BTN 视为确定有位置，并要求对手列表非空；这一路径无法识别名单中谁已全下，完整判断以 provider 路径为准。

2026-10-30 修复了原先“位置评分 > 0.5，而评分最大为 0.5”的不可达条件。修复也恢复了既有面对下注时的诈唬加注与持续下注位置加成；这些分支仍使用原频率，不包含在下面的普通诈唬条件概率说明中。

这些是到达该决策分支后的条件概率，不是所有行动中的诈唬占比。
纯诈唬要求位置；无位置半诈唬乘 0.6。概率除以仍在手牌中的对手人数，牌面危险程度达到 6 时再乘 0.5。听牌使压力下注更积极，但多人危险牌面仍会收紧。

原有持续下注分支独立使用 `cbet_frequency`，面对下注时继续按价格、胜率及风格决定跟注或弃牌。本次没有新增诈唬加注、阻挡牌策略或对手范围推断；仅使用当前牌手手牌及公开局面。

## 短码强牌跟注

翻牌后进入原有强牌分支（估计胜率至少 60%）时，剩余筹码不足跟满不再自动弃牌：跟注金额为跟注差额与剩余筹码中的较小值。加注总额必须超过当前桌面下注；不足或刚好只够跟注的全下不会再被报成加注。比当前下注高但低于最小完整加注的合法短全下仍由原规则处理。中弱牌赔率逻辑和六种风格频率未在此修复中调整。验证见 `docs/reports/2026-11-02-short-stack-call.md`。
