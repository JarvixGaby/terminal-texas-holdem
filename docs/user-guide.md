## 快速开始

### 1. 启动游戏
```bash
cd texas
./scripts/start.sh
```

### 2. 主菜单选择
启动后先输入 `1` 选择中文，或输入 `2` 选择 English。中文界面支持中文动作命令（过牌、跟注、下注、加注、弃牌），也保留英文命令；英文界面使用英文菜单和提示。

启动后您会看到主菜单：
```
🎮 德州扑克游戏
============================
1. 开始新游戏
2. 查看历史记录
3. 本地训练中心
4. 游戏说明
5. 玩家风格评测
6. 退出游戏
```

“本地训练中心”会读取同一玩家名的历史评测/统计，生成下一局可执行的训练重点；如果样本不足，会提示先完成可复盘样本。

### 3. 首次游戏建议
- 选择 "1. 开始新游戏"
- 推荐设置：2-3个玩家，1个AI
- 小盲注：5，初始筹码：1000

## 基础游戏

### 游戏设置

**玩家配置：**
- 人类玩家：只有您一个人类玩家
- AI玩家数量：1-9个（加上您共2-10人）
- 您的姓名：输入您的游戏昵称

**游戏参数：**
- 小盲注：建议5-10（大盲注自动为小盲注的2倍）
- 初始筹码：建议1000（至少是大盲注的50倍）

### 游戏流程

#### 阶段1：发牌和盲注
```
开始新的一手牌
============================
发放手牌...
机器人Alice 下小盲注: 5
机器人Bob 下大盲注: 10

你的手牌: A♠ K♥
你的筹码: 990
当前彩池: 15
```

#### 阶段2：翻牌前下注
```
你的回合
你的手牌: A♠ K♥
你的筹码: 990
当前彩池: 15
需要跟注: 10
可选动作: call, raise, fold
请选择动作 (check/call/raise/fold): 
```

**动作说明：**
- **call（跟注）**: 跟上当前最高下注
- **raise（加注）**: 提高下注金额
- **fold（弃牌）**: 放弃这手牌
- **check（过牌）**: 不下注（仅当无人下注时可选）
- **status**: 查看当前在场玩家状态
- **头像 / avatars**: 查看所有电脑牌手的像素头像；8 人桌等多人对局可随时调出完整头像墙
- **back**: 在确认环节返回重新选择

**新的交互体验：**
```
📊 当前在场玩家状态
==================================================
  🎮 张三: 990 筹码, 本轮下注: 10 (D)
  🎮 机器人Alice: 985 筹码, 本轮下注: 15
  ❌ 机器人Bob: 已弃牌

💰 当前彩池: 45
📈 最高下注: 15
👥 在场玩家: 2/3

🎯 张三 的回合
------------------------------
🃏 你的手牌: A♠ K♥
💎 你的筹码: 990
💸 需要跟注: 5

可选动作: call, raise, fold
额外选项: 'status' 查看玩家状态

请选择动作 (check/call/raise/fold/status): call
❓ 确认跟注 5 筹码？ (y/n/back): back
请选择动作 (check/call/raise/fold/status): raise

💰 加注设置:
   最小加注: 25
   最大加注: 990 (全押)
   当前需跟注: 5

请输入加注金额 (25-990) 或 'back' 返回: back
请选择动作 (check/call/raise/fold/status): call
❓ 确认跟注 5 筹码？ (y/n/back): y
```

#### 阶段3：翻牌、转牌、河牌
游戏会依次发出3张翻牌、1张转牌、1张河牌，每次发牌后都有一轮下注。

#### 阶段4：胜负判定
- **提前获胜**: 如果其他玩家都弃牌，剩余玩家直接获胜并得到彩池
- **摊牌**: 如果有多个玩家坚持到最后，展示手牌比较大小

**提前获胜示例:**
```
==============================
游戏结束
==============================

🏆 张三 获胜！（其他玩家都已弃牌）
💰 获得彩池: 245 筹码

张三 当前筹码: 1245
```

### 牌型大小（从大到小）
1. **皇家同花顺** - 10, J, Q, K, A 同花
2. **同花顺** - 五张连续同花牌
3. **四条** - 四张相同点数
4. **葫芦** - 三条 + 一对
5. **同花** - 五张同花牌
6. **顺子** - 五张连续牌
7. **三条** - 三张相同点数
8. **两对** - 两个不同对子
9. **一对** - 两张相同点数
10. **高牌** - 不符合以上牌型

## 复盘系统

复盘系统是本游戏的核心特色功能，让您以上帝视角重新体验牌局。

### 进入复盘模式

**方法1：快速复盘（推荐）**
1. 主菜单 → 查看历史记录 → 快速复盘 → 选择要复盘的牌局

如需先查看一手牌的基本信息，可以在历史记录菜单浏览最近牌局，并用列表中的游戏ID搜索详情。

**智能复盘特点：**
- 🎯 **关键动作聚焦**：自动停在raise/bet等重要决策点
- ⚡ **智能跳过**：自动跳过fold/check/call等常规动作
- ⭐ **清晰标记**：关键动作用星号标记
- 📊 **玩家风格**：每个玩家名旁显示风格emoji
- 📈 **详细进度**：显示当前阶段和动作位置

### 复盘控制命令

| 命令 | 功能 | 说明 |
|------|------|------|
| **回车键** | 下一步 | 查看下一个动作或阶段 |
| **b + 回车** | 上一步 | 返回上一个动作或阶段 |
| **s + 回车** | 显示胜率 | 查看当前阶段详细胜率分析 |
| **q + 回车** | 退出复盘 | 返回历史记录菜单 |

## 高级功能

### 胜率快速查看

在复盘过程中，每个有公共牌的阶段都会显示简化胜率：
```
📈 当前胜率估算:
------------------------------
  张三: 82.1%
  机器人Alice: 17.9%
```

### 手牌强度评估

系统会自动评估每个玩家的手牌：
- **强牌**: AA, KK, AK suited 等
- **中等牌**: 中等对子，A 加小牌等
- **弱牌**: 低对子，不相关的小牌
- **投机牌**: 小连牌 suited，小同花等

### 策略分析提示

复盘系统会在最后提供学习要点：
```
复盘要点:
----------------------------------------
• 观察各玩家在不同阶段的决策
• 分析胜率变化和关键转折点
• 学习不同位置的游戏策略
• 理解牌型发展过程
```

## 常见问题

### Q: 游戏记录保存在哪里？
A: 所有游戏记录自动保存在 `game_history.json` 文件中，无需手动操作。

### Q: 可以删除游戏记录吗？
A: 可以直接删除 `game_history.json` 文件来清空所有记录。

### Q: 胜率计算准确吗？
A: 使用蒙特卡洛模拟方法，进行数千次模拟计算，准确度很高（误差通常在1-2%以内）。

### Q: 为什么有时候胜率计算很慢？
A: 复杂情况下需要更多计算时间，可以稍等片刻。翻牌前计算相对较快。

### Q: 可以和朋友一起玩吗？
A: 目前支持多人在同一台电脑上轮流操作，未来可能增加网络对战功能。

### Q: AI 玩家的策略如何？
A: AI 使用基于概率和基本策略的决策系统，具有一定随机性，适合练习和娱乐。

## 游戏技巧

### 新手建议

1. **从观察开始**
   - 先玩几局熟悉流程
   - 观察AI的决策模式
   - 利用复盘功能学习

2. **使用新的UI功能**
   - 在每次行动前查看牌面、彩池和所需跟注额
   - 使用历史记录菜单中的“快速复盘”功能学习

3. **基础策略**
   - 紧凶打法：只玩好牌，玩的时候要有攻击性
   - 位置很重要：后位置有信息优势
   - 管理筹码：不要一次投入过多

4. **利用新功能学习**
   - 每局游戏后都复盘一次
   - 重点关注胜率变化的关键节点
   - 分析自己的决策是否合理

### 进阶技巧

1. **胜率理解**
   - 学会根据胜率调整下注策略
   - 理解听牌的概率和赔率
   - 掌握不同阶段的胜率变化

2. **复盘重点**
   - 关注关键决策点（大额下注时刻）
   - 对比实际结果和当时的胜率
   - 学习在不同胜率下的最优策略

3. **心理建设**
   - 接受运气成分，专注长期表现
   - 通过历史统计了解自己的真实水平
   - 用复盘系统客观分析得失

### 学习路径

**第1周：基础熟悉**
- 熟悉游戏操作和牌型
- 每天玩2-3局，每局都要复盘
- 重点学习翻牌前手牌选择

**第2周：策略提升**
- 开始关注位置和下注模式
- 学会利用胜率信息做决策
- 分析AI的不同行为模式

**第3周：深度分析**
- 重点复盘关键手牌
- 对比不同策略的长期效果
- 开始形成自己的游戏风格

## 技术支持

### 性能优化
- 如果胜率计算太慢，可以关闭详细分析功能
- 大量历史记录可能影响加载速度，建议定期清理

### 备份建议
- 重要的游戏记录可以备份 `game_history.json` 文件
- 可以在不同设备间传输历史记录

### 故障排除
- 如果程序出错，可以尝试删除历史记录文件重新开始
- 确保Python版本在3.6以上
- 检查终端是否支持UTF-8编码
