# 德州扑克终端游戏

[English README](../README.md)

这是一款本地运行的无限注德州扑克练习游戏。你可以与 1–5 位风格不同的电脑牌手对局，并在牌局结束后查看历史记录、复盘和训练建议。每次启动时先选择中文或英文。

## 运行环境与启动方式

- Python 3.12 或兼容的 Python 3 版本
- 支持 UTF-8 的终端
- 游玩无需安装第三方依赖

在项目目录运行：

```bash
./scripts/start.sh
```

也可以从其他目录通过脚本路径启动；或者在项目目录运行 `python3 main.py`。首次提示输入 `1` 选择中文，输入 `2` 选择英文。

## 开始对局

在主菜单选择“开始新游戏”，填写玩家名称，选择 1–5 位电脑牌手，并设置盲注和起始筹码。电脑牌手会使用不同的策略风格。

轮到你行动时，可以输入：

| 命令 | 作用 |
| --- | --- |
| `过牌` 或 `check` | 无需跟注时跳过下注。 |
| `跟注` 或 `call` | 跟上当前下注。 |
| `下注`、`加注`、`bet` 或 `raise` | 投入或提高下注，按提示输入金额。 |
| `弃牌` 或 `fold` | 放弃当前手牌。 |
| `状态` 或 `status` | 查看牌桌状态。 |
| `帮助` 或 `help` | 查看决策辅助分析。 |

两种界面语言都支持中文和英文动作命令。确认提示支持 `是`、`否`、`返回`，也支持 `y`、`n`、`back`。

主菜单还提供历史记录、快速复盘、本地训练中心、游戏说明和玩家风格评测。决策建议和胜率是练习用估算值，不保证是最佳行动。

## 本地数据

牌局历史、玩家统计、SQLite 数据库和日志保存在本机项目目录，相关运行文件已被 `.gitignore` 排除。游玩无需账号或网络连接。

## 开发与文档

在项目目录运行测试：

```bash
python3 -m pytest -q
```

程序入口为 `main.py`；终端翻译位于 `localization.py`；对局流程位于 `game.py`；历史记录与复盘分别位于 `game_history.py` 和 `quick_replay_system.py`。更多操作说明见[用户指南](user-guide.md)，文件结构见[项目索引](index.md)。
